# Конспект к экзамену по БПЛА (2026)

`uav-exam.pdf` — готовый конспект (32 с.):

1. Полёты БПЛА в России в 2026 году, Ленинградская область и Санкт-Петербург
2. Классификация БАС
3. Из чего состоит БАС: полётный контроллер, ESC, моторы, пропеллеры, рамы, АКБ, камеры, передатчики, антенны
4. Аналоговая и цифровая видеопередача
5. ПО: Betaflight, INAV, ArduPilot (+ вспомогательное)
6. Протоколы: UART, PWM, PPM, SBUS, CRSF, DShot и др.
7. Системы управления: ELRS, TBS Crossfire, FrSky и др.
8. Дальность связи: FSPL, бюджет линии, зона Френеля, радиогоризонт

В конце каждого раздела — вопросы для самопроверки.

## Сборка

Нужны XeLaTeX (TeX Live) и свободные шрифты PT Serif / PT Sans / PT Mono
(в Debian/Ubuntu — пакет `fonts-paratype`).

```
latexmk -xelatex uav-exam.tex
```

## Структура

```
uav-exam.tex   — корневой документ
uav-exam.sty   — оформление (шрифты, цвета, боксы, русские единицы siunitx)
sections/      — разделы 01–08 и список источников
img/           — иллюстрации (ArduPilot Wiki, CC BY-SA 3.0; документация Betaflight)
```

Нормативная часть актуальна на сентябрь 2026 года — региональные запреты меняются часто,
перед реальными полётами сверяйтесь с первоисточниками.
