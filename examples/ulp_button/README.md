# ULP: десять последовательных нажатых отсчётов

Проект для ESP-IDF 5.4.x, цель esp32s3. Это отдельный проект CMake, не скетч Arduino.
GPIO4 соединён через кнопку с GND и через внешний резистор 10 кОм с 3V3.
Другие нагрузки с GPIO4 отключить. Для лога удобен мост USB–UART.

В терминале с активированной средой ESP-IDF:

```
idf.py set-target esp32s3
idf.py build
idf.py -p COM5 flash monitor
```

COM5 заменяется своим портом. ULP опрашивает вход каждые 100 мс и будит основные ядра
после десяти подряд отсчётов LOW. После пробуждения основная программа ждёт секунду,
снова загружает ULP и засыпает. Отпустите кнопку в течение этой паузы.
Это фильтр по отсчётам, а не точное измерение длительности нажатия.
Данные обучения и настройки не сохраняются: цель опыта — увидеть два домена исполнения.

Проект составлен по API ESP-IDF; в этой среде ESP-IDF отсутствует, поэтому его сборка
и работа на плате здесь не проверены. Исходные примеры Espressif для сверки:
https://github.com/espressif/esp-idf/tree/v5.4/examples/system/ulp/ulp_riscv/gpio
