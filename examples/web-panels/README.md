# ESPUI и WiFiManager: воспроизводимые учебные примеры

Код хранится в code/l39_espui_hello.cpp, code/l39_espui_panel.cpp и code/l40_wifimanager.cpp.
После python export_sketches.py открывайте соответствующие папки sketches/ в Arduino IDE.
Цель: ESP32-S3 Dev Module, Arduino-ESP32 3.2.0; обычная схема разделов с OTA.

| Библиотека | Версия | Проверенный commit |
|---|---|---|
| ESPUI | 2.2.4 | `1eb5e2ffc4eebf3a854247fd5208a5b88edc051e` |
| ESP Async WebServer | 3.12.1 | `4d4eaca1833c3c11940a988fc8a6c0bdf734bbd2` |
| Async TCP | 3.5.0 | `9f03d11a3e7e0a2205c4d302446310f74f9e6380` |
| ArduinoJson | 7.4.2 | `1cd478f48e7c4cd142a0bd26ee17d63d70d04e3f` |
| WiFiManager | 2.0.17 | `4131fe617d01d746677e8b909379597162c2ca58` |

Точные репозитории записаны в dependencies.lock.json. Имена файлов заголовков не доказывают,
что IDE выбрала нужный fork: смотрите выбранные пути в журнале. На S3 нужен AsyncTCP,
а не ESPAsyncTCP. LittleFS входит в это ядро; в обоих ESPUI-примерах используется begin(),
ресурсы идут из прошивки и форматирования/загрузки файловой системы нет.

Первый пример создаёт S3-ESPUI, второй S3-Panel; учебный пароль lesson-39-demo.
WiFiManager создаёт S3-Setup по удержанию кнопки GPIO5 две секунды, пароль setup-40-demo.
Адрес читайте в Serial Monitor. Индивидуальный пароль для своей платы задайте до использования.
Панель: LED с резистором на GPIO4, движок потенциометра GPIO1. WiFiManager проверяется отдельно.
Два независимых сервера на порту 80 одновременно не запускаются.

ESPUI callback отправляет команды в очередь; модель и PWM изменяет loop().
Счётчик потерь очереди и публикация применённого состояния позволяют увидеть отказ обработки.
Это учебная схема, не система гарантированной доставки команд.

В ESPUI 2.2.4 WS_AUTHENTICATION выключен по умолчанию; HTTP Basic Auth сам по себе
не является подтверждением авторизации WebSocket-команд. Для проверки используется локальная AP.
Проверяйте каналы и права отдельно перед переносом в изделие.

Компиляция выполняется локально с зависимостями в tmp/espui-check;
глобальная библиотечная папка пользователя не меняется. Работа на физической плате,
браузерах и измерения задержек в этой среде не проверялись.
Все три примера успешно скомпилированы для ESP32-S3 с ядром 3.2.0 (24.10.2026).

## Установка точного набора для CLI

```
python tools/install_web_libraries.py --output tmp/web-libraries
arduino-cli compile --fqbn esp32:esp32:esp32s3 --libraries tmp/web-libraries sketches/l39_espui_panel
```

Запускайте из корня репозитория после экспорта скетчей. Каталог из --output создаётся отдельно;
скрипт не сбрасывает чужие изменения, не удаляет каталоги и отказывается менять несовпадающую копию.
Для воспроизведения нужен Git и доступ к официальным репозиториям. CI использует тот же lock-файл.

Сравнение альтернатив (ESP-DASH и GyverLibs Settings) дано в уроке 39.
Их программы в рамках этого дополнения не собирались.
