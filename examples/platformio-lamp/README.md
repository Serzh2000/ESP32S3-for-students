# Проект PlatformIO к уроку 41

Кнопка (GPIO5 — GND) переключает светодиод (GPIO4). Логика подавления дребезга вынесена в библиотеку
`lib/Debounce` и проверяется тестами на компьютере.

```
pio run                      # собрать
pio run -t upload            # собрать и записать в плату
pio device monitor           # монитор порта
pio test -e native           # тесты на компьютере (нужен компилятор g++ или gcc)
pio test -e esp32s3          # те же тесты на плате
pio run -e esp32s3_debug     # сборка с отладочной информацией (отладка — в уроке 35)
```

Платформа задана ссылкой на pioarduino, чтобы использовать Arduino-ESP32 3.x, как в остальной книге.
Сборка на плате и тесты на оборудовании здесь не проверялись; логику `Debounce` можно проверить командой `pio test -e native`.
