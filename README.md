# ESP32-S3: первые шаги в электронике и программировании микроконтроллеров

Учебник для детей и начинающих: 14 уроков по плате ESP32-S3-DevKitC-1 и Arduino-ESP32 3.x.
Основы языка C++ (переменные, условия, циклы, массивы, функции) вводятся постепенно,
в разделах «Учимся программировать» — ровно тогда, когда они впервые встречаются в скетчах
(в таблице выделены курсивом). Книга начинается со знакомства с платой и понятий об аналоговом и цифровом сигнале, а каждая
схема нарисована в двух видах: монтажная (на макетной плате) и принципиальная электрическая.

## Структура

```
main.tex               — корневой документ: подключает стиль и главы
esp32s3-course.sty     — оформление: шрифты, цвета, боксы, листинги
esp32s3-bb.sty         — рисование монтажных схем: макетная плата, DevKitC-1, детали, провода
chapters/              — титул, уроки 01–14, приложение A
code/*.cpp             — все примеры кода (исходники), префикс lNN — номер урока
code/*.tex             — подсвеченные версии, генерирует highlight.py
highlight.py           — подсветка кода через Pygments
```

## Сборка

Нужны XeLaTeX (TeX Live 2023 или новее) и Python с Pygments. Если в системе есть шрифты
Cambria, Calibri, Consolas (Windows), используются они; иначе — свободные PT Serif, PT Sans и
DejaVu Sans Mono.

```
python highlight.py
latexmk -xelatex main.tex
```

`highlight.py` нужно запускать после каждого изменения в `code/*.cpp`.

## Монтажные схемы

Схемы на макетной плате рисуются макросами из `esp32s3-bb.sty` в стиле `bb`
(одна единица = шаг отверстий 2,54 мм):

```latex
\begin{twoview}{Подпись рисунка}{fig:метка}
\begin{tikzpicture}[bb]
  \bbBoard{24}                       % макетная плата на 24 столбца
  \bbDevKit{29}{25}                  % отладочная плата, координаты выводов (dk-4), (dk-GND)…
  \bbR{10}{13}{14}{13}{rr}{rr}{rn}   % резистор 220 Ом
  \bbLED{red}{14}{11}{-1.8}          % светодиод
  \draw[wire=wyellow] (dk-4) -- (10,22) -- (10,14);
\end{tikzpicture}
\nextview
\begin{circuitikz} … \end{circuitikz}   % принципиальная схема
\end{twoview}
```
