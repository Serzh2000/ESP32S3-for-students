# ESP32-S3: практический курс программирования микроконтроллеров

Учебно-методическое пособие ОДОД МОБУ «СОШ «ЦО «Кудрово».
Авторы-составители — Корягин Сергей Андреевич и Полякова Полина Алексеевна, педагоги дополнительного образования.

Вводные главы и сорок четыре урока (с 0 по 43) по ESP32-S3 (Arduino-ESP32 3.x, плата ESP32-S3-DevKitC-1).
Каждый урок — это отдельные опыты: объяснение идеи, готовый пример, самостоятельный опыт,
разбор типичных ошибок, вопросы «Проверь себя» и по шесть заданий четырёх уровней сложности (★ — ★★★★).

## Структура

```
main.tex               — корневой документ: подключает стиль и главы
esp32s3-bb.sty         — макетные платы, детали и провода для монтажных схем
esp32s3-course.sty     — оформление: шрифты, цвета, боксы, листинги, нумерация
chapters/title.tex     — титульный лист и его оборот
chapters/00-workplace.tex — техника безопасности, макетная плата, мультиметр
chapters/00-signals.tex, chapters/00-pins.tex — сигналы и выводы из ранней версии
chapters/00-basics.tex — вводная глава «Перед первым уроком»
chapters/00…43-*.tex   — уроки 0–43
chapters/B…G-*.tex     — приложения (справочник, компоненты, словарь, шпаргалка по C++, ответы, педагогу)
code/*.cpp             — все примеры кода (исходники)
examples/platformio-lamp — проект PlatformIO к уроку 41 (библиотека, тесты, отладка)
examples/tinyml        — обучение и экспорт нейросетей на NumPy к уроку 42
code/*.tex             — подсвеченные версии, генерирует highlight.py
highlight.py           — подсветка кода через Pygments
sketches/              — готовые скетчи по урокам: arduino/ (Arduino IDE) и platformio/ (один проект, окружение на скетч)
export_sketches.py     — создаёт sketches/ из code/*.cpp
.github/workflows/     — CI: сборка книги (PDF), компиляция всех скетчей для ESP32-S3 (PlatformIO и Arduino CLI), проверка examples/
```

## Сборка PDF

Нужны XeLaTeX (TeX Live 2025), Python с Pygments и шрифты Cambria, Calibri, Consolas
(есть в Windows; при отсутствии автоматически выбираются PT Serif, PT Sans и DejaVu Sans Mono).

```
python highlight.py
latexmk -xelatex main.tex
```

`highlight.py` нужно запускать после каждого изменения в `code/*.cpp`.
Пакет `minted` не используется: его помощник `latexminted` из TeX Live 2025 несовместим с Python 3.14.

## Скетчи не только в книге

Все примеры лежат готовыми к запуску в папке `sketches/` (указатель с библиотеками — `sketches/README.md`):

- `sketches/arduino/<урок>/<скетч>/<скетч>.ino` — открывается в Arduino IDE;
- `sketches/platformio/` — один проект PlatformIO, на каждый скетч своё окружение: `pio run -e l1_blink -t upload`;
- `examples/` — проекты побольше: PlatformIO с тестами (`platformio-lamp`), TinyML на NumPy, ESP-IDF и ULP, версии библиотек для ESPUI.

Источник правды — `code/*.cpp` (из него же собирается книга). После правки примера запустите
`python export_sketches.py` и добавьте обновлённую папку `sketches/` в коммит. Файлы-фрагменты
(без `setup()`) в `sketches/` не попадают: их вставляют в готовый скетч по тексту урока.

## ESPUI и настройка Wi-Fi

Урок 39 содержит два полных примера ESPUI; урок 40 — отдельный пример WiFiManager.
Сравнены ESP-DASH, GyverLibs Settings и собственный интерфейс на ESPAsyncWebServer.
Точные зависимости и правила установки: [examples/web-panels/README.md](examples/web-panels/README.md).
В курсе 42 урока, четыре вводные главы и 276 заданий. Итоговый проект — урок 43.
Полный учебный маршрут — 120 часов; предыдущие модули можно проходить отдельно.

Три примера ESPUI/WiFiManager также скомпилированы локально: вместе с расширением по S3
проверено 14 новых Arduino-примеров. Аппаратные проверки не выполнялись.

## PlatformIO и TinyML (уроки 41 и 42)

Два урока стоят перед итоговым проектом, который теперь последний (урок 43): **41** описывает
`platformio.ini`, структуру проекта, версии библиотек, тесты на компьютере и отладку (проект
[examples/platformio-lamp](examples/platformio-lamp)); **42** проводит через весь цикл TinyML — данные,
обучение на NumPy, квантование весов в int8, встраивание в прошивку и измерения
(скрипты [examples/tinyml](examples/tinyml), три скетча `code/l42_*.cpp`).
Теперь в книге 44 урока, четыре вводные главы и 288 заданий; полный маршрут — 128 часов.

Что проверено: скрипты обучения запускались, ошибка сети по синусу измерена (float32 0,026; int8 0,044),
логика тестов `Debounce` проверена независимой моделью на Python. Не проверялось: сборка PlatformIO-проекта
и `pio test` (в среде не было PlatformIO и компилятора C++), компиляция трёх новых скетчей (их проверит CI)
и работа на оборудовании. Фрагмент TensorFlow Lite Micro в уроке 42 — схема, её нужно сверять с версией библиотеки.
