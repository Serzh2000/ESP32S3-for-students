# ESP32-S3: практический курс программирования микроконтроллеров

Учебно-методическое пособие ОДОД МОБУ «СОШ «ЦО «Кудрово».
Авторы-составители — Корягин Сергей Андреевич и Полякова Полина Алексеевна, педагоги дополнительного образования.

Вводные главы и сорок два урока (с 0 по 41) по ESP32-S3 (Arduino-ESP32 3.x, плата ESP32-S3-DevKitC-1).
Каждый урок — это отдельные опыты: объяснение идеи, готовый пример, самостоятельный опыт,
разбор типичных ошибок, вопросы «Проверь себя» и по шесть заданий четырёх уровней сложности (★ — ★★★★).

## Структура

```
main.tex               — корневой документ: подключает стиль и главы
esp32s3-bb.sty         — макетные платы, детали и провода для монтажных схем
esp32s3-course.sty     — оформление: шрифты, цвета, боксы, листинги, нумерация
chapters/title.tex     — титульный лист и его оборот
chapters/00-workplace.tex — техника безопасности, макетная плата, мультиметр
chapters/00-signals.tex, chapters/00-pins.tex — сигналы и выводы из ранней версии
chapters/00-basics.tex — вводная глава «Перед первым уроком»
chapters/00…41-*.tex   — уроки 0–41
chapters/B…G-*.tex     — приложения (справочник, компоненты, словарь, шпаргалка по C++, ответы, педагогу)
code/*.cpp             — все примеры кода (исходники)
code/*.tex             — подсвеченные версии, генерирует highlight.py
highlight.py           — подсветка кода через Pygments
export_sketches.py     — раскладывает примеры по папкам sketches/<имя>/<имя>.ino
.github/workflows/     — CI: компиляция всех примеров для ESP32-S3
```

## Сборка PDF

Нужны XeLaTeX (TeX Live 2025), Python с Pygments и шрифты Cambria, Calibri, Consolas
(есть в Windows; при отсутствии автоматически выбираются PT Serif, PT Sans и DejaVu Sans Mono).

```
python highlight.py
latexmk -xelatex main.tex
```

`highlight.py` нужно запускать после каждого изменения в `code/*.cpp`.
Пакет `minted` не используется: его помощник `latexminted` из TeX Live 2025 несовместим с Python 3.14.

## Примеры для Arduino IDE

```
python export_sketches.py
```

Каждую папку `sketches/<имя>` можно открыть в Arduino IDE. Файлы-фрагменты (без `setup()`)
вставляются в готовый скетч по тексту урока.

## ESPUI и настройка Wi-Fi

Урок 39 содержит два полных примера ESPUI; урок 40 — отдельный пример WiFiManager.
Сравнены ESP-DASH, GyverLibs Settings и собственный интерфейс на ESPAsyncWebServer.
Точные зависимости и правила установки: [examples/web-panels/README.md](examples/web-panels/README.md).
В курсе 42 урока, четыре вводные главы и 276 заданий. Итоговый проект — урок 41.
Полный учебный маршрут — 120 часов; предыдущие модули можно проходить отдельно.

Три примера ESPUI/WiFiManager также скомпилированы локально: вместе с расширением по S3
проверено 14 новых Arduino-примеров. Аппаратные проверки не выполнялись.
