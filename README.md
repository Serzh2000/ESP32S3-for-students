# Базовый курс ESP32-S3

Десять последовательных уроков по ESP32-S3 (Arduino-ESP32 3.x, плата ESP32-S3-DevKitC-1)
со сквозным проектом «умная лампа»: каждый урок добавляет в неё одну новую возможность.

| Урок | Тема | Шаг проекта |
|---|---|---|
| 0 | Знакомство с чипом и настройка среды | знакомство с проектом |
| 1 | Цифровой выход | светодиод лампы и «пульс» на RGB |
| 2 | Последовательный порт (UART) | команды `on` / `off` из Serial Monitor |
| 3 | Цифровой вход, дребезг, прерывания | кнопка-выключатель |
| 4 | ШИМ (LEDC), гамма-коррекция | плавная яркость |
| 5 | АЦП | ручка яркости |
| 6 | Шина I²C, OLED-дисплей | экран состояния |
| 7 | FreeRTOS: задачи, очереди, мьютексы | лампа на задачах |
| 8 | Wi-Fi и веб-сервер | управление через браузер |
| 9 | Сон и энергосбережение | засыпание и пробуждение кнопкой |

Приложение A — полный код лампы (`code/lamp_full.cpp`), приложение B — справочник.

## Структура

```
main.tex               — корневой документ: подключает стиль и главы
esp32s3-course.sty     — оформление: шрифты, цвета, боксы, листинги
chapters/              — титул, уроки 00–09, приложения A и B
code/*.cpp             — все примеры кода (исходники)
code/*.tex             — подсвеченные версии, генерирует highlight.py
highlight.py           — подсветка кода через Pygments
```

## Сборка

Нужны XeLaTeX (TeX Live 2025), Python с Pygments и шрифты Cambria, Calibri, Consolas
(есть в Windows; на других системах замените их в `esp32s3-course.sty`).

```
python highlight.py
latexmk -xelatex main.tex
```

`highlight.py` нужно запускать после каждого изменения в `code/*.cpp`.
Пакет `minted` не используется: его помощник `latexminted` из TeX Live 2025 несовместим с Python 3.14.
