\section{Чек-лист перед первым полётом новой модели}

\begin{enumerate}[label=\chkbox]
  \item Выбрана правильная модель, приёмник привязан, Model Match настроен.
  \item Все рули ходят в правильную сторону и не упираются.
  \item Газ: минимум стика = мотор стоит; отсечка/арм работают.
  \item Failsafe проверен выключением пульта (без пропеллеров!).
  \item Телеметрия приходит, тревоги по батарее и связи настроены.
  \item Таймер запускается по арму/газу.
  \item Аккумуляторы модели и пульта заряжены.
  \item Проверка дальности пройдена.
\end{enumerate}
