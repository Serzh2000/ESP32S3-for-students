# EdgeTX на RadioMaster TX12 и Boxer

Практическое руководство (XeLaTeX) по настройке аппаратуры управления RadioMaster TX12 (MKI/MKII)
и RadioMaster Boxer под прошивкой EdgeTX 2.10–2.12 с ExpressLRS 3.x/4.x.

| Глава | Тема |
|---|---|
| 1 | Знакомство с пультами: органы управления, отличия TX12 и Boxer, аккумуляторы, режимы стиков |
| 2 | Что такое EdgeTX: путь сигнала, главный экран, кнопки, карта меню |
| 3 | Обновление прошивки и SD-карты, ELRS и мультипротокольного модуля |
| 4 | Первое включение и системные настройки (калибровка, звук, батарея, Hardware) |
| 5 | Модели: создание, таймеры, триммеры, предполётные проверки |
| 6 | Радиомодули: ExpressLRS (привязка, частота пакетов, мощность, режимы каналов) и Multi |
| 7 | Входы: расходы, экспонента, триммеры |
| 8 | Миксеры: AUX-каналы, элевоны, V-хвост, флапероны, отсечка газа |
| 9 | Выходы и кривые |
| 10 | Полётные режимы (в т.ч. 6POS на Boxer) и глобальные переменные |
| 11 | Логические переключатели |
| 12 | Специальные функции и голосовые сообщения |
| 13 | Телеметрия |
| 14 | Lua-скрипты (с примерами в `lua/`) |
| 15 | Тренер и симуляторы |
| 16 | Готовые рецепты: квадрокоптер, самолёт, крыло, планер, машина |
| 17 | Диагностика неполадок |

Приложения: A — шпаргалка и чек-лист, B — структура SD-карты, C — словарь терминов.

## Структура

```
main.tex           — корневой документ
edgetx-book.sty    — оформление: шрифты, цвета, боксы, «экран» 128×64
chapters/          — титул, предисловие, главы 01–17, приложения A–C
lua/               — примеры Lua-скриптов (вставляются в книгу как есть)
```

## Сборка

```
latexmk -xelatex main.tex
```

Нужен XeLaTeX (TeX Live) с пакетами polyglossia, tcolorbox, pgfplots, siunitx, fvextra.
Шрифты: Cambria/Calibri/Consolas, если установлены; иначе автоматически используются
Liberation Serif/Sans и DejaVu Sans Mono.
