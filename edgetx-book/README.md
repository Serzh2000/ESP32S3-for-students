# EdgeTX на RadioMaster TX12 и Boxer

Практическое руководство (XeLaTeX) по настройке аппаратуры управления RadioMaster TX12 (MKI/MKII)
и RadioMaster Boxer под прошивкой EdgeTX 2.10–2.12 с ExpressLRS 3.x/4.x.

Книга написана простым языком (для школьников и новичков), на «ты», с большим количеством
векторных иллюстраций: пульты с подписями, самолёт и квадрокоптер в разных проекциях,
экраны пульта 128×64, временные диаграммы, схемы прохождения сигнала.

| Глава | Тема |
|---|---|
| 1 | Знакомство с пультом: органы управления TX12 и Boxer, типы переключателей и их значения |
| 2 | Как управляется модель: оси крен/тангаж/рыскание, стики Mode 2, самолёт vs квадрокоптер, каналы |
| 3 | EdgeTX — «фабрика сигналов», главный экран, навигация по меню |
| 4 | Обновление прошивки, SD-карты, ExpressLRS и мультипротокольного модуля |
| 5 | Первое включение: предупреждения, калибровка, порядок каналов, батарея, звук, Hardware |
| 6 | Модели: создание, таймеры (с диаграммой режимов), предполётные проверки |
| 7 | Радиомодуль и привязка: ExpressLRS, частота пакетов, телеметрия, failsafe, Multi |
| 8 | Входы: расходы и экспонента |
| 9 | Миксеры: AUX-каналы, элевоны, V-хвост, отсечка газа, Slow/Delay |
| 10 | Выходы и кривые |
| 11 | Полётные режимы (6POS на Boxer) и глобальные переменные |
| 12 | Логические переключатели (с временными диаграммами) |
| 13 | Специальные функции, голос, логи |
| 14 | Телеметрия |
| 15 | Lua-скрипты (примеры в `lua/`) |
| 16 | Учитель–ученик и симуляторы |
| 17 | Готовые рецепты: квадрокоптер, самолёт, крыло, планер, машина |
| 18 | Что-то не работает? Пошаговый поиск неисправностей |

Приложения: A — шпаргалка и чек-лист, B — структура SD-карты, C — словарь терминов.

## Структура

```
main.tex           — корневой документ
edgetx-book.sty    — оформление: шрифты, цвета, рамки, разметка интерфейса
edgetx-pics.tex    — библиотека рисунков TikZ: пульты, модели, стики, сервы, экран 128×64
chapters/          — титул, предисловие, главы 01–18, приложения A–C
lua/               — примеры Lua-скриптов (вставляются в книгу как есть)
```

## Сборка

```
latexmk -xelatex main.tex
```

Нужен XeLaTeX (TeX Live) с пакетами polyglossia, tcolorbox, pgfplots, siunitx, fvextra.
Шрифты: Cambria/Calibri/Consolas, если установлены; иначе автоматически используются
Liberation Serif/Sans и DejaVu Sans Mono.
